# CLIRL
`Command Line Interface Roguelike`

CLIRL is a simple, Java-based roguelike designed to be played in the terminal of your choice. 

</div>

---

CLIRL was created as a showcase of introductory Java concepts for those interested in learning the language. Specifically, this program showcases the practical functionality of Object-Oriented Programming. Through the use of classes, constructors, and objects, CLIRL highlights the valuable implementation of abstraction, encapsulation, and association.

The exigence for this particular program was to provide an example for a project I designed for some classmates preparing for the AP Computer Science A exam. Thus, this particular program provides an idea of how one could achieve the creation of a terminal-based Roguelike using Java-specific concepts and code.

To view the project outline in question, you may do so [here](PROJECT_OUTLINE.md). All the code and documentation related to this project and example is available within this repo under the [MIT License](LICENSE).

> Note: Yes, I deliberately wrote this code using the old Java syntax. Although you have been able to shorthand things like the `main` class declaration or substitute `System.out.*` for `IO.*` since JDK 24 (March 2025), I believe it's valuable to familiarize yourself with the original form too. Besides, many examinations and certifications, like AP CSA, may require you to write in the pre-JDK 24 syntax.
